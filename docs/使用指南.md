# OpenMount 使用指南

OpenMount 把 WebDAV 或 SFTP 服务器挂载成 Windows 里的一个驱动器。文件按需读取，写入先落到本地缓存再上传，断网时写入不会丢。

## 1. 准备

1. 安装 [WinFsp](https://winfsp.dev/rel/) 2.1（`winget install WinFsp.WinFsp`）。这是系统驱动，只需装一次；安装后若提示重启，请重启后再打开 OpenMount。
2. 便携版解压即用，无需安装 .NET；自行构建时按 README 准备 `bin\rclone.exe`。
3. 系统要求：Windows 10 1809 及以上或 Windows 11，x64。

启动后程序常驻托盘。关闭主窗口只是隐藏，驱动器保持连接；托盘右键"退出"才会断开全部驱动器并退出。

## 2. 添加驱动器

点"添加驱动器"，依次填写：

| 区域 | 说明 |
| --- | --- |
| 存储 | 选 WebDAV、SFTP，或 Nextcloud / ownCloud / Synology / QNAP / ASUSTOR 预设（自动填好端口与路径） |
| 挂载点 | 盘符；勾选"作为本地磁盘"后也可挂到本地 NTFS 磁盘上一个尚不存在的文件夹 |
| 名称 | 显示为卷标，各驱动器不可重复 |
| 凭据 | 保存在 Windows 凭据管理器 / 仅本次运行期间记住 / 每次连接时询问 |
| 连接信息 | WebDAV：协议、主机、端口、路径、认证方式（账号密码 / 匿名 / Bearer Token）、服务器类型、证书校验；SFTP：主机、端口、账号、密码或私钥、远程目录、主机密钥 |

- "程序启动时自动连接"和"连接断开后自动重连"默认开启。
- 默认以网络驱动器出现在"网络位置"；勾选"作为本地磁盘"后出现在"设备和驱动器"，少数只接受本地盘的软件需要它。
- 点"连接"保存并立即连接，点"仅保存"只保存。
- 列表里每张卡片右侧的"…"可以编辑、复制（沿用连接信息，重新选盘符并输入凭据）或删除驱动器。

### WebDAV 注意事项

- 使用 http 时账号密码与文件内容不加密传输，界面会标出"明文 HTTP"。
- 证书不受信任时可以导入自定义 CA 证书；"忽略校验"会放弃对服务器身份的验证，只建议在可信局域网使用。

### SFTP 注意事项

- 首次连接会显示服务器的主机密钥指纹，请与服务器管理员提供的指纹核对一致后再信任；之后密钥变化时会阻断连接并提示。
- 远程目录相对账号主目录，以 `/` 开头为绝对路径，留空为主目录。
- 私钥为 OpenSSH 格式，带口令的私钥在"私钥口令"里填写。

## 3. 状态怎么看

每张卡片同时显示三类状态，它们相互独立：

| 类别 | 含义 |
| --- | --- |
| 已连接 / 已断开 / 连接中 / 重连中 / 需要登录 / 需要确认主机密钥 / 连接失败 | 驱动器本身的状态 |
| 远端暂不可达 / 远端要求重新认证 / 远端拒绝访问 / 远端路径不存在 | 已连接但服务器当前有问题；挂载保持，远端恢复后自动继续 |
| N 个待上传 / 正在上传 / 保留了 N 个待上传文件 / 同步状态待确认 | 本地缓存里还有没上传完的内容 |

"已连接"只表示盘符存在，不代表远端一切正常，也不代表所有写入都已上传。点"详情"可以看到更完整的信息、缓存占用和实际使用的 rclone 命令行。

## 4. 断开、退出与未上传数据

断开、删除、退出时如果还有文件没上传完，会先询问：

- **等待上传完成后断开**：继续等待，长时间无进展时再次询问。
- **停止并保留待上传数据**：立即断开，缓存保留，下次连接时自动继续上传。
- **丢弃未上传数据**：永久删除本地副本，单独确认。

有未上传文件时关机或注销也会收到同样的提示（可在设置中关闭）。

## 5. 设置

| 页 | 项目 |
| --- | --- |
| 常规 | 登录后自动启动、手动连接后打开资源管理器、驱动器类型图标、桌面通知 |
| 代理 | 不使用 / 系统代理 / 自定义；只对勾选了"使用代理"的驱动器生效 |
| 缓存 | 缓存目录、每个驱动器的清理目标（默认 10G，不是硬上限，未上传的文件不会被清理）、缓存保留时间（24h）、磁盘最小剩余空间（2G） |
| 高级 | rclone 日志级别、有未上传文件时阻止关机、日志目录 |
| 依赖 | WinFsp 与 rclone 的检测与路径 |

设置即时保存。缓存按驱动器各自计算，三个驱动器各用默认值时最多各占 10 GB。

## 6. 数据目录与便携模式

| 位置 | 内容 |
| --- | --- |
| `config\drives.json`、`settings.json` | 驱动器与设置 |
| `config\known_hosts` | 已信任的 SFTP 主机密钥 |
| `cache\<驱动器ID>\` | 每个驱动器的本地缓存 |
| `logs\`、`logs\drives\` | 主程序日志与每个驱动器的 rclone 日志 |

默认位于 `%LOCALAPPDATA%\OpenMount`。程序目录里有 `portable.txt` 时改用旁边的 `data\`（便携模式）；环境变量 `OPENMOUNT_ROOT` 优先于两者。密码与令牌不写在这些文件里，而是保存在 Windows 凭据管理器。

设置页底部可以导出 / 导入配置：默认不含密码，选择"包含已保存的凭据"时用口令加密。导入的驱动器不会自动连接，请检查盘符与凭据后手动连接。

## 7. 命令行

程序已在运行时，再次执行 `OpenMount.exe` 会把参数转交给运行中的实例。

| 参数 | 作用 |
| --- | --- |
| `--minimized` | 启动但不显示窗口（开机启动使用） |
| `--show` | 显示主窗口 |
| `--connect "名称或盘符"` / `--disconnect "名称或盘符"` | 连接 / 断开一个驱动器 |
| `--connect-all` / `--disconnect-all` | 连接 / 断开全部 |
| `--exit` | 退出（有未上传数据时会先询问） |

## 8. 常见问题

**资源管理器里出现"断开连接的网络驱动器"残留。** 正常使用不会出现；若程序被强制结束过，下次启动时会自动清理。

**提示"挂载点已被占用"。** 盘符已被别的程序或映射使用，换一个盘符，或把目标文件夹换成尚不存在的路径。

**SmartScreen 提示"未知发布者"。** 便携版尚未代码签名，点"更多信息 → 仍要运行"。

**连接后文件读取很慢。** 首次读取需要从服务器下载，之后命中本地缓存；可在驱动器高级选项里调整缓存模式与带宽限制。缓存模式建议保持 `full`，`minimal` 与 `off` 不保留离线写入。

**想重置全部配置。** 退出程序后删除数据目录（便携版为 `data\`），凭据需在 Windows 凭据管理器中删除 `OpenMount/` 开头的条目。

**连接意外断开了。** 程序每分钟检查一次挂载是否正常；一次检查失败不会断开，3 秒后再次失败才会按"挂载丢失"处理并自动重连。主程序日志里的 `alive check failed` 行记录了失败的步骤（进程 / RC 接口 / 盘符 / 卷身份）、原因和当时的上下文，驱动器详情的"最近错误"也会显示；反馈问题时请附上这两行。

**日志在哪里。** 主窗口"日志"按钮可实时查看，文件在数据目录的 `logs\` 下；日志不含密码与令牌。
